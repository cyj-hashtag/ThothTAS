# 草稿保护与 Basic-3 反弹失步修复（v0.3.2）

新增未保存提示、草稿检查点及异常退出恢复。编辑器和普通Host会话停用非确定性同进程重置；重新回放恢复固定存档并启动独立游戏进程。这个版本恢复了启动等待，没有解决原生物理状态的同进程恢复。

## 找回的草稿

旧版退出时留下263字节的Basic-3备份，已逐字节复制为本机 `examples/basic-3-recovered.tas`。现有 `basic-3.tas` 当时与Basic-2相同，未被覆盖。私人脚本和原始运行日志没有上传到公开仓库。

## 分歧证据

用户实际暖重置日志中，同一162帧脚本连续三次出现三个随机记录SHA。入场基线已有Bouncer `startFreezeTimer=-0.18` 与 `-0.19`、`frameCount=2` 与 `1` 的区别，说明入场推进的物理步数不同。随机日志第355次调用、输入帧22的Bouncer噪声参数随后不同。

REA重新核对了原版程序集SHA和MVID，Evidence为 `ev_32d819f034c1c5f31cbac0c8471ab95c617396375edc5ee4623818bd66d05121`。反编译并核对原始CIL确认：Bouncer按原生接触点反射方向，满足碰撞间隔条件时再消耗三次Unity随机调用改变方向和速度。静态代码只能解释机制；实际日志证明了物理步数和随机记录分歧。不能把问题归结为某个方向输入写错，也没有修改敌人反弹算法来固定向上。

## 实际验证

| 流程 | 结果 |
|---|---|
| Basic-3原版：5次连续＋暂停＋逐帧＋0.5×＋2× | 9个独立进程逐帧状态、完整随机记录一致 |
| Basic-3社区v2.8：同样9次 | 同一配置下全部一致 |
| 最终自动入口的草稿保护测试 | 真实中英文退出弹窗；取消、保存、不保存、磁盘写入失败；强制终止独立编辑器后恢复，全部通过 |
| 最终自动入口的编辑器回放 | 3个原版与2个社区独立进程，逐帧与随机记录一致；取消退出保留控制连接；Host与原始TCP重置命令均被拒绝 |
| Basic-1/2编辑器回归 | 高亮、行段进度、不可变快照、过关提示、可靠重新回放、自然拼接及实际TCP断线暂停通过 |

最初9＋9次基线检查使用修改前的游戏模块；最终5次入口验证使用最终游戏模块、Host和编辑器。JSON保存每个实际进程PID、模块SHA、完整帧与随机记录SHA及检查范围。一次早期自测因测试辅助代码读取已释放进程的PID失败，修复辅助代码后复测通过；没有当作游戏确定性失败或通过证据。

**一致不代表过关。** 找回的337帧草稿在固定冷启动基线上，两种程序集配置均于第122帧死亡。此前暖回放的第233帧过关依赖另一种进程物理状态；恢复稿保留原始输入，需要以可靠基线重新调整。没有把它声明为已通过的单关TAS。

## 使用与自动复核

停止键入350ms后，草稿原子写入 `work/draft-recovery`；失焦和正常退出也会写入。它不覆盖正式TAS。关闭、打开其他文件、生成拼接草稿前提示保存；取消或保存失败保留窗口。成功保存清理当前检查点，下次启动会提示恢复遗留检查点，工具栏“恢复草稿”也能预览旧版TAS备份。

```powershell
.\scripts\Verify-DraftReplay.ps1 -ScriptPath .\examples\basic-1.tas
```

该入口要求已经创建独立游戏副本并准备社区Mod，运行真实编辑器和游戏后生成JSON。用户本机本次原始报告位于 `work/bugfix-basic3/entrypoint-final` 和 `work/bugfix-basic3/editor-editing`；其他原始资料仍在 `work/bugfix-basic3`。

尚未保证任意电脑或所有玩法路径一致，未重新运行全部关卡验收；系统文件选择对话框取消及突然断电未自动化验证。异常退出测试确实强制终止了工具自己启动的编辑器，检查点原子写入并要求磁盘flush；最后350ms内尚未写入的键入仍可能在突发终止时丢失。
