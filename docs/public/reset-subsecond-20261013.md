# 同进程重置：一秒以内的实际游戏验证

2026-10-13，THOTH TAS 0.3.1。当前电脑与固定游戏指纹，实际运行 Unity 游戏；测量从控制器请求重置到玩家激活后的完整第0帧边界。未用 UI 返回、模拟或编译成功代替运行验证。

**23 次当前模块的实际暖重置全部低于一秒，范围 414.0～649.4ms。** 原版当前 Basic-1 的五次中位数为 518.8ms；社区计时器加当前 Basic-1→Basic-2 拼接的五次中位数为 538.9ms。此前相同 Basic-1 的中位数为2552.3ms，本次减少约79.7%等待。

## 如何使用

启动更新后的 `dist/Launch-Editor.cmd`，勾选“重新回放”旁的“同进程快速重置”，然后点击“重新回放”。首次启动仍需正常加载并建立缓存；切换社区配置或窗口尺寸需要新进程。每次重置仍冻结新草稿、恢复固定存档并建立独立记录目录。

## 改动与证据

原来的约2.3秒耗时在启动声音库的重建过程。新版保留7个声音库根、901个Transform、860个AudioSource，以及37个已核对的声音选择器/加载组件；重置时停止旧播放及延迟播放，恢复音量、音调、声像、循环、音源设置、初始层级、兄弟顺序、组件字段和静态引用。原声音加载器识别已存在的单例，跳过重复加载声音场景。

玩家、敌人、子弹、物理场景、对象池、音乐及其他持久根仍重新创建。未知声音库脚本、丢失组件或包含物理实体的声音库拒绝缓存；已销毁缓存导致明确错误，不能静默复用。首次版本校验和持续读锁继续有效。

本次重新用 REA 核对原始程序集身份，并保留 ILSpy 反编译和原CIL。声音加载器及声音库加载方法没有直接 Unity 随机调用；实际音效选择方法仍按原算法消费随机数。本次没有改变游戏随机算法或游戏物理步长。完整私有逆向证据位于 `work/reset-subsecond/inspect` 和 `rea-evidence.json`，本公共包不包含原游戏程序集或CIL全文。

## 验证结果与边界

- 原版Basic-1与社区模式两关拼接各完成冷启动加5次同进程重置。每组保留同一真实PID；初始玩家位置、零输入、存活和未过关基线检查通过。全部随机记录SHA256与各自冷启动一致，实际完成帧数分别为274与495。
- 每组五次暖重置的GameObject、Mesh、Material、Texture和持久根数量没有逐次增长；这只是此次有限重复检查，不能推断无限时长无泄漏。
- 当前模块的Basic-1冷启动帧记录与随机记录与v0.3.0逐字节一致。
- 社区模式拼接脚本6次独立进程验证：两次连续播放、暂停继续、逐帧、0.5×、2×。全部495帧，完整状态/随机/阶段比较通过。
- 功能轮测在同一进程内切换Basic-2、死亡、传送、Boss、碰撞、Seed=2；每项两次，再测试34次逐帧、650ms暂停和变速。13次重置均到达实际指定起点并完成回放；暂停期间帧与随机摘要保持不变。原用户的两份脚本、settings与磁盘游戏程序集哈希保持一致。

**暖重置仍 `coldEquivalent=false`。** 上述Basic比较虽然完整随机记录相同，状态里的原生绝对时间、声音计时及部分实体浮点字段仍有差异。JSON列出了整个回放每个差异字段的首次帧/值、差异次数和最大数值差异，没有将其抹平或宣布精确一致。

更长的死亡、传送、Boss、碰撞和在长进程内改变种子的路径，其暖回放随机记录确实出现分歧；轮测的“功能通过”仅表示重置和操作成功。复测旧v0.3.0死亡路径也失败，两个旧暖回放在第190输入帧开始出现随机调用差异。首次失败记录及随后有明确功能范围的轮测都保留在 `work/reset-subsecond`。正式TAS结果继续以新进程 `verify` 为准，不能把本次提速解释为即时存档或完全确定性的同进程重放。

## 自动复测

```powershell
.\dist\host\ThothTAS.Host.exe verify-reset .\examples\basic-1.tas --count 5
.\dist\host\ThothTAS.Host.exe compose --out .\work\combined-check.tas .\examples\basic-1.tas .\examples\basic-2.tas
.\dist\host\ThothTAS.Host.exe verify-reset .\work\combined-check.tas --community-mod --count 5
.\dist\host\ThothTAS.Host.exe verify .\work\combined-check.tas --community-mod --count 5 --modes
```

结果、每次模块哈希、PID、加载阶段、完整随机SHA256及逐帧差异摘要见[机器可读报告](reset-subsecond-20261013.json)。程序同时保留本机实际 `frames.jsonl`、`random.tsv`、`phases.tsv` 和运行日志。未验证所有关卡、跨电脑、长期稳定性或音频听感完全一致；初次加载不计入一秒以内暖重置指标。
