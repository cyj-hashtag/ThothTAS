# 示例输入与脚本契约

`basic-1.tas` 是任务提供的四段脚本。`coordinates.tas` 展示方向简写、负数、小数和固定世界坐标。示例用于展示语法，实际游戏覆盖和确定性验证结论以项目的真实验证报告为准。

文件采用 UTF-8；允许 BOM、空行和以 `#` 开始的整行注释。首个有效指令必须为 `Version,1`，`Start` 和可选的 `Seed` 必须在输入段之前；省略 `Seed` 时使用 1。关卡标识区分大小写，解析时由实际关卡清单检查。

```text
Version,1
Start,Basic-1
Seed,1

60, M=45, A=270
60, M=45, A=(30,40)
30, N
60, M=0.5:0, A=1:0
```

角度以右方为 0°、上方为 90°、左方为 180°、下方为 270°；负角度和超过一周的有限角度归一化到一周。`M=x:y` 和 `A=x:y` 保留不超过 1 的向量幅度，超过 1 的向量归一化到单位长度；游戏运行模块仍使用原有死区和射击节奏。`A=0:0` 表示停火。

移动简写允许 `U`、`D`、`L`、`R`，斜方向写为 `UR` 或 `U,R`。斜方向归一化到单位长度。重复方向、同时指定相反方向、简写与 `M` 或 `N` 同时出现都会报错。`N` 可与 `A` 同时使用。

`A=(x,y)` 使用游戏世界 XY 单位；括号内逗号保留在一个字段中。每帧从当前射击位置重新计算单位方向，射击位置与目标完全重合时返回零向量。运行模块应通过 `TasFrameInput.ResolveAim` 计算，不能在入段时只计算一次。

每段只保持该段指定的输入，未指定的移动或瞄准归零。帧数必须为正整数，脚本总帧数不能超过 `2147483647`。种子为 32 位有符号整数。数值使用小数点，可使用科学记数法；NaN、无穷值和数值溢出报错。

`GetInputAtFrame` 使用从 0 开始的帧号，第一个有效帧为 0，最后一个有效帧为 `TotalFrames - 1`；同时返回该段的源文件行号。报错包含行和字段列，便于编辑器定位。

独立契约测试入口：

```powershell
dotnet run --project D:\Workspace4All\ThothTAS\tests\ThothTAS.Core.Tests\ThothTAS.Core.Tests.csproj -c Release
```

此入口测试脚本解析和数学契约，不启动游戏，不能替代实际游戏确定性验收。
